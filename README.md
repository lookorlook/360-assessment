# 360° 环评诊断看板

> 端到端 360 度胜任力评价工具：Excel 题库 → 飞书问卷 → 数据看板

## 背景

在企业管理中，360 度评估是衡量干部胜任力的核心工具。传统流程需要：
- 手动设计问卷、分发纸质/邮件评价表
- 人工汇总评分、计算维度均分
- 用 Excel 做图表，反复调整格式

这个项目把全流程自动化：
1. **解析** 线下 Excel 题库（自动识别 Sheet、维度、题目、评价人）
2. **创建** 飞书多维表格 + 在线表单（评价人扫码/点击即可填写）
3. **处理** 收集到的评价数据（按平级/下级分组、计算均分/标准差）
4. **生成** 交互式 HTML 看板（KPI 卡片、雷达图、热力图、明细表格）

## 适用范围

- 360 度干部胜任力评价
- 绩效考核中的多方评价
- 晋升/转岗候选人的能力诊断
- 任何需要「题库→问卷→看板」三阶段的数据收集分析场景

支持的题库格式见下一节，**不限制 Sheet 名称、列位置、题目编号方式**。

## 题库格式

题库 Excel 包含三个 Sheet（名称可自定义）：

### Sheet 1: 题库（自动识别）

```
被评价人：张三          ← 身份信息（必须「被评价人：」开头）
职级：部门经理           ← 身份信息（必须「职级：」或「职位：」开头）
360度 领导力胜任评价表    ← 表名（维度前的任意文本行）

战略思维                ← 维度名（纯中文 2-8 字，独占一行）
一、能从全局角度分析业务趋势。（战略视野）  ← 题目
二、将公司战略分解为可执行目标。（目标拆解）
三、在市场变化时快速调整策略。（灵活应变）

团队管理                ← 下一个维度
一、准确识别团队成员的优势。（识人用人）
...
```

### Sheet 2: 评价人（自动识别）

| 级别 | 人员 | 职位 |
|------|------|------|
| 上级 | 李四 | 事业部总经理 |
| 平级 | 王五 | 市场部经理 |
|      | 赵六 | 技术部经理 |
| 下级 | 孙八 | 高级工程师 |

### Sheet 3: 评分标准（自动识别）

```
5分：持续高频展现此能力，可作为标杆示范。
4分：经常展现此能力，表现稳定可靠。
3分：能够展现此能力，基本达到要求。
2分：偶尔展现此能力，仍需加强。
1分：尚未展现此能力，需重点关注。
无法判断
```

完整模板 → [题库模板-360环评.xlsx](https://github.com/zcl0411/360-assessment/blob/main/assets/题库模板-360环评.xlsx)

## 使用方法

### 方式一：WorkBuddy SKILL（推荐）

安装 Skill 后，在对话中直接说：

```
"帮我生成 360 看板，题库是这个 Excel"（拖入文件）
"检验这个题库能不能用"
"用这张表创建一个飞书问卷"
```

Skill 会自动完成所有步骤，不需要安装 Python 或任何依赖。

### 方式二：命令行

```bash
# 1. 检验题库
python scripts/parse_excel.py "题库文件.xlsx"

# 2. 创建飞书问卷（dry-run 预览）
python scripts/create_feishu_form.py "question_bank.json" --dry-run

# 3. 生成看板
python scripts/generate_dashboard.py "题库.xlsx" "数据.json" --output "看板.html"
```

## 看板功能

生成的 HTML 看板包含：

| 模块 | 内容 |
|------|------|
| KPI 卡片 | 综合平均分、最高/最低维度、平级 vs 下级对比、最大分歧项 |
| 维度对比 | 水平柱状图（平级 vs 下级）+ Chart.js 雷达图 |
| 题目得分 | 全部题目按均分排序，标注标准差 |
| 评价矩阵 | 评价人 × 题目热力图，颜色编码分数高低 |
| 主题 | 深色主题，适配各种显示环境 |
