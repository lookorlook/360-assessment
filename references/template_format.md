# 题库 Excel 格式说明

## 自动检测规则

解析器不依赖固定的 Sheet 名称或列位置，通过以下规则自动识别：

### Sheet 角色识别

| Sheet 角色 | 识别关键词（名称） | 内容模式 |
|-----------|-----------------|---------|
| 题库 | 评价表、胜任力、问卷、360、环评 | 有维度行（纯中文短词）或题目行（编号+描述） |
| 评价人 | 评价人、名单、人员 | 表头含"级别/关系"，数据有"上级/平级/下级" |
| 评分标准 | 辅助、勿删、选项、评分 | 包含"N分"格式或"无法判断" |

### 题库 Sheet 解析规则

1. **身份信息**: 以「被评价人：」「职级：」「职位：」开头的行
2. **表名**: 维度出现之前，长度>=4 的非题目非维度文本
3. **维度**: 纯中文 2-8 字，独占一行，不带编号或标点
4. **题目**: 必须带编号前缀
   - 支持: `一、二、三` / `1. 2. 3.` / `①②③`
   - 格式: `编号、描述。（标签）` 或 `编号、描述`
   - 标签放在中文全角括号（）中

### 评价人 Sheet 解析规则

1. 第一行是表头，列名含识别关键词
2. 级别列必须是「上级」「平级」「下级」
3. 同级人员的级别格可留空（自动继承上一格）

### 评分标准 Sheet 解析规则

1. 必须包含「N分」格式（如 5分、4分...）
2. 必须包含一行「无法判断」或「N/A」或「不适用」
3. 放在哪一列都行，解析器会扫描所有列
